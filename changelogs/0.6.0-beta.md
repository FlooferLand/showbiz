Welcome to the first beta release!

Showbiz is still in very early access, however you can now rest assured that your world will not combust into a million pieces due to the mod.
Do note that things **will** still break, be changed, or stop working, especially between large releases like these.

This update contains so many changes we couldn't fit them here, so there are likely things we've missed

### Breaking changes
- The `any` keyword on bitmaps was fixed, and it will now run correctly on any bitmap and be used as a fallback for shows that don't use a known chart
- Show parsers might be the wrong way around and might have to be manually replaced
- Addons using the old flow system will display a warning to migrate to the new syntax
- There may be other things, back up your worlds!

### Features
- Replaced and greatly improved the spotlight system _(added support for both Veil and IRLights, as well as a vanilla block-based lighting engine)_
- Added RR-compatible air sim and flow controls for addon developers and proper physics to bots _(thanks to Reda Karimi!)_
- Added accurate in-scale Billy Bob and Looney Bird models by LBN
- Added a way to set the curtain speed on the curtain controller
- Added stereo audio for speakers
- Added shader shadow support for bot entities _(required annoyingly porting to `LivingEntity`)_
- Added a prop system and the moonshine/rock stage props
- Added cylinder sounds to bot entities _(accidentally missed while porting)_
- Added collide and deco parts to bot entities _(accidentally missed while porting)_
- Added a work-in-progress variant system for bots
- Added addon and mod version checking when joining servers
- Added support for CEC analog bits (`held yes` in the bitmap)
- Added a bitchart for the FNaF 2 toy animatronics
- Added the red Showbiz entrance door
- Added the Showbiz dinner chair

### Quality of life
- Added a visual for finding erroring bots
- Added instructions for downloading FFmpeg when you right-click the TV
- Improved the command system and added a statistics command for server owners
- Improved the curtain rendering and added curtain grouping
- Slightly improved the TV texture
- Made the curtains stop hanging down on corners and cleaned the curtains up a bit
- Made the curtain controller use the new bit picker
- Made the reel-to-reel emit a redstone signal while playing
- Made the reel-to-reel continue playing running shows when you log back in
- Made the reel-to-reel unload shows that aren't playing and haven't been touched in a while
- Made the mod able to load any show, as long as the file extension ends in `shw` (excludes ProgramBlue shows since we can't support those)

### Fixes
- Fixed Wolfman's bowtie being too large/low
- Fixed some bugs with deltatime on wiggle bones (@RedaKarimi)
- Fixed Chica's cupcake being a separate fixture in the `faz` bitchart
- Fixed a bug where the game could crash on first launch due to `showbiz\shows` missing
- Fixed the TV not updating its hanging state
- Fixed FFmpeg 9.0 video info failing to parse due to multiple streams / stream groups
- Fixed edit screens showing a black background when using shaders
- Fixed GeckoLib items moving around in the hotbar
- Fixed the audio continuing to play for a chunk when you stop/pause a show, and not playing for a chunk when you start/unpause one
